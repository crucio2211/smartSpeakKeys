Smart Speak Keys Filter

Version: 3.0.1
Author: Rosendo Barde Hubilla Junior
Minimum NVDA Version: 2026.1

Overview

Smart Speak Keys Filter is an NVDA add-on that gives you fine-grained control over which keys NVDA announces when the Speak Command Keys feature is turned on. By default, NVDA will speak every key you press when this setting is enabled. This add-on silences keys that are usually distracting to hear — such as navigation keys and common editing shortcuts — while still letting NVDA announce the keys you actually want to hear.

The behavior is inspired by how JAWS handles keystroke announcement, where common shortcuts are silent by default.

Requirements

  • NVDA 2026.1 or later
  • The Speak Command Keys option must be turned ON in NVDA settings for this add-on to have any effect. You can toggle it with NVDA+4 or find it under NVDA Menu → Preferences → Settings → Keyboard.

Installation

  1. Download the smartSpeakKeys.nvda-addon file.
  2. Open the file with NVDA (press Enter on it, or go to NVDA Menu → Tools → Manage Add-ons → Install).
  3. Follow the prompts to install and restart NVDA.
  4. Make sure Speak Command Keys is enabled. The add-on does nothing if this setting is off.

How It Works

The add-on intercepts every keystroke before NVDA announces it. It checks whether the key should be silenced based on two sources of rules:

  1. Hardcoded rules — a fixed list of common shortcuts that are always silent, regardless of your settings.
  2. User-configured rules — keys and modifier combinations you choose to suppress via the settings dialog.

If a key matches either rule, NVDA will not announce it. Everything else is announced normally.

Hardcoded Silent Keys

The following keys are always silent and cannot be changed from the settings dialog. They are silenced whether or not their modifier is listed in your suppressed modifiers.

Ctrl + Letter Shortcuts

  • Ctrl+A — Select All
  • Ctrl+C — Copy
  • Ctrl+V — Paste
  • Ctrl+X — Cut
  • Ctrl+Z — Undo

Ctrl + Tab

  • Ctrl+Tab — Switch to next tab
  • Ctrl+Shift+Tab — Switch to previous tab

Navigation Key Combinations

  • Ctrl+Home — Jump to beginning of document
  • Ctrl+End — Jump to end of document
  • Ctrl+Page Up — Jump up by a large amount
  • Ctrl+Page Down — Jump down by a large amount
  • Ctrl+Shift+Home — Select from cursor to beginning
  • Ctrl+Shift+End — Select from cursor to end
  • Ctrl+Shift+Page Up — Select upward by a large amount
  • Ctrl+Shift+Page Down — Select downward by a large amount
  • Shift+Home — Select to beginning of line
  • Shift+End — Select to end of line
  • Shift+Page Up — Select upward by one page
  • Shift+Page Down — Select downward by one page

Opening the Settings

You can configure which additional keys are suppressed by going to:

NVDA Menu → Preferences → Settings → Smart Speak Keys Filter

The settings category uses accessible checkable lists (the same kind of list NVDA itself uses for NVDA modifier keys) and has two sections:

1. Suppress ALL combos using these modifier keys

If you check a modifier here, every key combination that uses that modifier will be silenced. For example, if you check NVDA, then NVDA+any key will never be announced. The available modifiers are:

  • NVDA — The NVDA key (Insert or CapsLock)
  • Ctrl — The Control key
  • Alt — The Alt key
  • Shift — The Shift key
  • Win — The Windows key

Note: The hardcoded rules above always apply even if a modifier is NOT checked here.

2. Suppress individual keys (no modifier)

These checkable list items let you silence specific keys when pressed alone, without any modifier. For example, if you check Home, pressing the Home key by itself will be silent. Numpad keys are listed individually. The available keys are:

  • Arrow keys: Up, Down, Left, Right
  • Navigation: Page Up, Page Down, Home, End
  • Tab, Escape
  • Delete, Backspace
  • Function keys: F1 through F12

Default Settings

When the add-on is first installed (or after pressing Reset to Defaults), the following settings are active:

  • Suppressed modifier: NVDA (all NVDA+key combos are silent)
  • Suppressed individual keys: Up Arrow, Down Arrow, Left Arrow, Right Arrow, Tab, Delete, Backspace

Saving and Resetting Settings

  • Click OK to save your changes. Settings are saved to a file inside your NVDA user configuration folder and will persist across NVDA restarts.
  • Click Cancel to discard any changes.
  • Click Reset to Defaults to restore the original default settings (you still need to click OK to save).

Tips and Common Scenarios

I want NVDA to stay completely silent while I type and navigate

In the settings dialog, check all five modifier keys (NVDA, Ctrl, Alt, Shift, Win) and check all individual keys. This will silence virtually everything.

I only want to hear letter and number keys, nothing else

Check all modifiers and all individual keys in the settings dialog. The hardcoded shortcuts will also remain silent automatically.

I want to hear F-keys but not arrow keys

In the individual keys section, uncheck F1–F12 and keep the arrow keys checked.

I want to hear all Ctrl combinations except the ones already hardcoded

Make sure Ctrl is NOT checked in the modifier section. Only the hardcoded Ctrl shortcuts (A, C, V, X, Z, Tab, Home, End, Page Up, Page Down, and their Shift variants) will be silent.

Uninstalling

  1. Go to NVDA Menu → Tools → Manage Add-ons.
  2. Find Smart Speak Keys Filter in the list.
  3. Press the Disable or Remove button.
  4. Restart NVDA when prompted.

Troubleshooting

Keys are still being announced even though I configured them to be silent.
Make sure Speak Command Keys is enabled in NVDA settings. The add-on only filters announcements when this setting is on.

The add-on settings do not appear.
Open NVDA Menu → Preferences → Settings and look for the Smart Speak Keys Filter category. If it is missing, restart NVDA. If it still does not appear, check the NVDA log (NVDA Menu → Tools → View Log) for any errors related to smartSpeakKeys.

I changed my settings but they did not take effect.
Make sure you clicked OK and not Cancel in the settings dialog. Your settings are applied immediately after clicking OK without needing to restart NVDA.
